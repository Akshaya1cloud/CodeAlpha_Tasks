# ConnectX – Video Meeting Application

ConnectX is a real-time video meeting web application that allows users to create and join online meetings. It provides essential collaboration features such as video calling, audio calling, screen sharing, real-time chat, and a collaborative whiteboard.

## Features

- 🔐 User Registration and Login
- 🎥 Real-time Video Calling
- 🎤 Audio Calling
- 🖥️ Screen Sharing
- 💬 Real-time Meeting Chat
- 📝 Collaborative Whiteboard
- 👥 Participant Count
- ⏱️ Meeting Timer
- 🔗 Create and Join Meetings using Room ID
- 👤 User Profile and Dashboard
- 🚪 Secure Logout

## Technologies Used

- Socket.IO
