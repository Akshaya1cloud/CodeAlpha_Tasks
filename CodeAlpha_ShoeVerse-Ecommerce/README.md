# ShoeVerse - Full Stack E-Commerce Website

## 📌 Project Overview

ShoeVerse is a full-stack e-commerce website developed as part of the CodeAlpha Internship. It allows users to register, log in, browse products, search for shoes, view product details, add items to the cart, and proceed to checkout.

---

## ✨ Features

- User Registration & Login (JWT Authentication)
- Secure Logout
- Product Listing
- Product Details Page
- Search Products
- Shopping Cart
- Checkout Page
- Responsive User Interface

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT (JSON Web Token)
